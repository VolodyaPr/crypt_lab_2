# Запуск проекта

Проект представляет собой реализацию и статистическое исследование методов сокрытия информации в изображениях с использованием модификации младших битов (LSB), криптографической защиты (AES-128-GCM + PBKDF2) и псевдослучайного распределения данных.

---

## 1. Зависимости

Для работы программы необходим **Python 3.8+** и следующие библиотеки:

* `numpy` — для работы с массивами пикселей и генерации данных;
* `pillow` (`PIL`) — для загрузки, сохранения и обработки изображений;
* `matplotlib` — для построения карт разности и гистограмм;
* `scipy` — для проведения статистического χ²-теста;
* `cryptography` — для криптографического шифрования (AES-GCM, PBKDF2).
* `scikit-image` — для вычисления метрики структурного сходства изображений (SSIM).

Установка зависимостей:
```bash
pip install numpy pillow matplotlib scipy cryptography scikit-image
```

## 2. Запуск
### Запуск с изображением по умолчанию (gradient.png)
```bash
python -m src.main
```
### Запуск с заданным изображением (файл должен находиться в папке imgs)
```bash
python -m src.main checkerboard.png
```

## 3. Параметры
Основные параметры конфигурации задаются в файле config.py:

* `PASSWORD` — пароль для генерации ключа шифрования.
* `KDF_ITER` — количество итераций PBKDF2.
* `IMGS_DIR` — путь к папке с исходными и стего-изображениями (imgs).
* `RESULTS_DIR` — путь к папке для сохранения метрик и графиков (results).

#### Уровни заполнения
В качестве сообщения используются данные сгенерированные с помощью генератора случайных чисел (`np.random.default_rng` с фиксированным seed = 42). 
Сообщение встраивается с нагрузкой **1%** и **5%** от максимальной емкости изображения. Для зашифрованных режимов размер исходной полезной нагрузки автоматически уменьшается на размер криптографического оверхеда, чтобы итоговый объем байтов в контейнере оставался одинаковым во всех методах.

## 4. Результаты
Для каждого обрабатываемого изображения (например gradient.png) в каталоге results создаются следующие файлы:

* Стегограммы для уровней 1% и 5%: `gradient-plainLsb_1-percent.png`, `gradient-plainLsb_5-percent.png` и т.д.
* Сводная таблица метрик: gradient_metrics.csv
* Карта разности: gradient_difference.png (для метода RandLSB на 5%)
* Сравнительная гистограмма: gradient_histogram.png

Расшифрование и проверка корректности выполняются автоматически в момент выполнения скрипта. Отдельные файлы с расшифрованным текстом или промежуточными данными не создаются.
